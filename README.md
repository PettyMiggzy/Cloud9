# Cloud 9 Physical Therapy

A redesigned site for [Cloud 9 Physical Therapy](https://cloud9physicaltherapy.com/), the one-to-one clinic at 5370 E. Thompson Rd, Suite G, Indianapolis.

Photographs come from the current site: the clinic, the real team, and one treatment photo of Dr. Skye with a patient. Stock and generated pictures of other people are not used. Hours, fees, services, and patient reviews are the clinic’s as well. Appointment requests open an email to contact@cloud9pt.com. They are not confirmed until the clinic replies.

## Run it

```bash
npm install
npm run dev
```

The dev server listens on [http://127.0.0.1:4317](http://127.0.0.1:4317).
