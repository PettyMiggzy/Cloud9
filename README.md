# Cloud 9 Physical Therapy

A redesigned site for [Cloud 9 Physical Therapy](https://cloud9physicaltherapy.com/), the one-to-one clinic at 5370 E. Thompson Rd, Suite G, Indianapolis.

The photographs of the clinic, the team, and the partner marks come from the current site. Hours, fees, services, and patient reviews are theirs as well. Appointment requests open an email to contact@cloud9pt.com. They are not confirmed until the clinic replies.

## Run it

```bash
npm install
npm run dev
```

The dev server listens on [http://127.0.0.1:4317](http://127.0.0.1:4317).
